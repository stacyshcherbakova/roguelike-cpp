# Design Doc — XYZ Roguelike

Рабочая шпаргалка по дипломному проекту курса «C++ для разработки игр 1.0». Направление — **программист игровой логики (Gameplay Developer)**, уровень — средний с частью сложного (инвентарь с зельями).

## 1. Общее описание

| | |
|---|---|
| Жанр | 2D-рогалик с видом сверху, бой в ближнем бою |
| Цель | пройти три локации подряд: зачистить комнату, убить босса, выйти в открывшуюся дверь |
| Герой | искательница приключений (анимированный спрайт из курса), 100 HP, 5 брони, удар на 20 |
| Враги | фиолетовые слизни: ждут, пока игрок подойдёт, потом преследуют и кусают (50 HP, 2 брони, 12 урона) |
| Боссы | красный слизень у двери каждой локации: больше здоровья (120 / 200 / 300), бьёт на 22 и раз в 4 секунды делает рывок через комнату |
| Что делать | бегать (WASD), бить ближайшего врага (пробел), подбирать зелья и пить их (E), найти открывшуюся дверь справа |
| Поражение | при 0 HP текущая локация перезапускается, счётчик смертей показывается на экране победы |
| Победа | дверь третьей локации → экран «YOU WON», R — начать заново |

## 2. Механики и фичи

### Было до диплома (ДЗ 10–11)

- компонентный движок `XYZEngine`: `GameObject` + компоненты, системы рендера, физики (AABB, кинематические тела, триггеры) и ресурсов;
- игрок с камерой, движением, анимацией и коллайдером; враг с `SeekerComponent`; стены и пол из тайлов;
- звуки и музыка (`AudioComponent`, `MusicComponent`);
- логгер с уровнями и приёмниками, ассерты и исключения, заглушка вместо отсутствующей текстуры;
- `HealthComponent` (HP + броня), `AttackComponent` (урон, дальность, перезарядка, авто-атака), атака игрока по пробелу.

### Добавлено в дипломе (направление Gameplay)

| Уровень | Фича | Реализация |
|---|---|---|
| лёгкий | **несколько карт с переходами** | `LevelDefinition` описывает локацию (размер, число врагов, тайлы, сила босса, число зелий). `GameLevel` строит `Arena` с проёмом под `Door`. `RoguelikeGame` держит список локаций и переключает их через `GameWorld::RunLater` в конце кадра |
| лёгкий | **дверь** | закрытая — твёрдый тайл, открытая — триггер (`ColliderComponent::SetTrigger`); открывается, когда `aliveEnemies == 0` и босс мёртв |
| средний | **босс на каждой карте** | `Boss`: `SeekerComponent` + `AttackComponent` + `ChargeComponent` (рывок к игроку раз в 4 с, 900 px/с, 0.5 с); здоровье масштабируется по локации; смерть босса открывает дверь |
| сложный (часть) | **инвентарь и предметы** | `InventoryComponent` (движок) считает предметы; `Potion` — триггер на полу, при касании игрока добавляется в инвентарь; E — `PlayerControllerComponent` тратит зелье и лечит на 40 |
| бонус | **HUD** | `ScreenTextComponent` (движок) рисует текст в координатах окна поверх мира; `Hud` показывает HP, броню, зелья, локацию, число врагов и состояние босса; подсказка по управлению внизу |
| бонус | **экран победы** | после третьей двери — текст с числом смертей, `KeyActionComponent` на R перезапускает игру |
| служебное | **отладочная клавиша F2** | в Debug-сборке принудительно открывает дверь — для демонстрации переходов без зачистки |

## 3. Оценка по сложности (сторипоинты)

Шкала: 1 — полчаса, 2 — пара часов, 3 — полдня, 5 — день, 8 — несколько дней.

| Задача | SP | Комментарий |
|---|---|---|
| Описание локаций и класс игры с переключением | 2 | понадобился `RunLater`, чтобы не ломать мир из колбэка компонента |
| Дверь-триггер и проём в стене | 2 | доработка `Arena` (openings), аксессоры в `Trigger`/`Collision` |
| Исправление коллайдеров на первом кадре | 1 | найдено тестом перехода: игрока выталкивало за стену |
| Босс + рывок | 3 | отдельный `ChargeComponent`, баланс здоровья по локациям |
| Инвентарь + зелья | 2 | `InventoryComponent`, `Potion`, кнопка E |
| HUD и экран победы | 3 | текст в экранных координатах, шрифты в `ResourceSystem` |
| Документация, релиз, PR | 2 | README, этот документ, Release-сборка с exe |
| **Итого** | **15** | |

## 5. Работа с Git

Ветки:

- `main` — стабильные состояния, помечены тегами `hw10`, `hw11`, `diploma`;
- `feature/level-transitions` — локации, дверь, переходы, фикс коллайдеров;
- `feature/boss` — босс и рывок;
- `feature/inventory-hud` — инвентарь, зелья, HUD, экран победы;
- `docs/diploma` — README, этот документ, скриншоты;
- `fix/wall-push-through` — исправления после проверки: выталкивание из стен, раздельные тайлы появления врагов, очистка экрана победы;
- `fix/wall-seam-slide` — скольжение вдоль стены без остановки на стыке тайлов: из стен тело выталкивается начиная с самого глубокого пересечения.

Каждая ветка вливалась в `main` через pull request на GitHub с коротким описанием, что сделано (список PR — в README). Сообщения коммитов — одно предложение о сути изменения.

## 6. Что можно сделать дальше

- генератор лабиринта вместо прямоугольной арены (`MazeGenerator` из уроков);

- сохранение прогресса между запусками;
- полноценная панель инвентаря с иконками (направление UI).
